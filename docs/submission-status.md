```sh
python3 tests/solver7_optimization_test.py

python3 tests/solver7_search_assembly_test.py

python3 tools/validate_submission_models.py
```

For exhaustive C validation use the commands in
`measurements/solver7_search/README.md`. For the current assembly sweep:

```sh
python3 tools/prepare_submission_sweep.py --out measurements/my_new_sweep
python3 tools/run_final_validation.py ripes --workers 4 --out measurements/my_new_sweep
```

The runner patches only the 14 input bytes in the pinned ELF, checks an optimal
11-move path, independently replays it and retains every raw Ripes result. The preparation script copies the rebuilt ELF and its source dependencies into a
fresh output directory. Never reuse checkpoints with a different fingerprint.
